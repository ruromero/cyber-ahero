# Cyber AHERO

Game launcher styled like a 2000s internet café, for amateur LAN parties on
modern and Windows XP laptops. C99 + SDL2, Windows only; see README.md.

No triage labels; notes carry category tags only. See `docs/agents/triage-labels.md`.

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
